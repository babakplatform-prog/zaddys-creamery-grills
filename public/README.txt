# Zaddys Logo Assets Folder

Save your Zaddys logo image here with the following filename:
  zaddys-logo.png
(or logo.png)

Supported formats:
  - PNG (with transparent background recommended)
  - SVG
  - JPG / JPEG
  - WebP

The web application automatically detects and displays this file at the bottom center of the menu.
If no file is uploaded yet, an SVG replica will be rendered automatically.
